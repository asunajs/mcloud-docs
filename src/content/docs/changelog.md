## 当前开发版

- 直播口令接入 CLI 配置开关，默认关闭。
- WebSocket 与固定小红书主页 HTML 作为同级来源并行采集，合并去重后由当前账号领取。
- 统一 Node.js 与 txiki.js WebSocket Runtime Adapter。
- Node.js 和 txiki.js CLI 均可构建为单文件，第三方运行依赖内联。
- 修复红包派对模块级 token 导致的多账号串号。
- 修复直播口令在多账号调度中可能重复遍历账号的问题。
- 修复配置迁移状态和根 workspace 测试入口。
- `fail` 明确为 info 级业务结果；只有 `error` / `fatal` 表示运行错误。
- 微信签到、微信抽奖和摇一摇已过期，不再实现。

## v2.1.0

- 新增推送日志级别配置 `minLevel`。
- 优化红包派对日志输出。
- 将 `fail` 输出调整为 info 级业务结果。

## v2.0.0

- 引入 v2 配置结构和多包架构。
- 新增小红花口令兑换与独立兑换入口。
- 推进 Node.js / txiki.js 双运行时支持。

## 历史功能说明

早期版本曾实现微信签到、微信抽奖和摇一摇。对应活动或接口现已过期；历史记录仅用于说明版本演进，不代表当前可用能力。
